# GoMap v0.4.10

> 升级主机发现策略，修复首页整体超时与错误链，并收紧 UDP 开放判定。现有 SDK 结果结构保持不变，但默认探测行为和部分结果会变化。

## 对比基线

以 `v0.4.9` 与本版本的实际源码差异为准。开发分支与此前发布分支的历史已合并，不把重复的端口-only SDK 提交计为新增能力。

## 新增能力

- 独立 SDK `Scanner.DiscoverHosts(ctx, targets, opts)`：接受 IP/CIDR，支持零值 Scanner，默认并发 32、目标上限 65,536；不执行正式端口扫描或服务识别。
- 独立 CLI `gomap host`：默认逐行输出已确认存活 IP；`-jl` 输出各目标 SDK JSON，`-v` 输出摘要。无信号不称为离线；执行失败或取消返回非零退出码。
- `gomap port -nf`：跳过 TCP 服务识别，保留端口发现；可与 `-Pn` 组合。SDK 的 `DisableServiceFingerprint` 已在 `v0.4.9` 提供。
- 保留 `go run ./cmd/main.go ...` 单文件入口兼容。

## 主机发现默认行为变化

未指定 Modes 时，不再固定串行执行 ICMP → TCP Connect，而是根据平台、路由、接口和权限自动选择：

| 场景 | 自动策略 |
| --- | --- |
| Linux 直连以太网 IPv4，ARP 可用 | ARP-only；正常无回应不追加 IP 探测 |
| Linux 非直连 IPv4 | ICMP Echo + TCP SYN；SYN 不可用时降级 Connect |
| Linux IPv6、macOS | ICMP Echo + TCP Connect |
| Windows | TCP Connect |

- 默认 TCP 判活端口为 `80,443,22,445,3389,8080,3306,6379`；显式 Ports 完整覆盖默认。
- Connect 收到连接拒绝也确认主机存活，但不表示该端口开放。
- 使用原生探针，不再调用 `ping`、`nping` 或 `arping`。Linux 支持原生 ICMPv4/v6、IPv4 SYN/ACK 和直连以太网 IPv4 ARP；macOS 原生支持 ICMPv4/v6；Windows 保留 Connect。
- 显式 Modes 仍按指定顺序执行；TCP ACK 不会由自动策略发送。
- 有效命中优先；至少一项有效执行但正常无信号时返回未确认；全部无法有效执行时通过既有 error 通道返回原因，取消和配置错误独立处理。
- 批量前置发现并发上限为 32，加强分发、探测和扫描阶段的 context 取消处理。

`Scan/ScanTargets` 的可选前置发现保持可用，与独立入口复用同一实现。调用方若接受新策略，无需增加配置；需要固定模式时可显式指定有序 Modes，但这不恢复旧实现或旧错误语义。

## 首页探测修复

- 默认整体时限 10 秒；调用方 context deadline 覆盖默认，端口扫描 Timeout 不再作为首页整体预算。
- DNS、连接、TLS、主请求、重定向、正文、兼容重试和 favicon 共用整体截止时间；取消中断实际 HTTP 请求。
- 移除库内原有较短的连接、响应头和单请求固定超时。
- 保留底层错误链，支持 `errors.Is/As` 分类 DNS、连接、TLS、超时及响应读取失败。
- favicon 自身失败可保留主页面；整体 deadline 到期则整个首页调用失败，不把部分完成当作成功。

仍保留空正文不可达、跨地址重定向/favicon、正文按字节裁剪等既有边界；本次不增加爬虫、网络范围隔离或主动 Web 应用指纹实现。

## UDP 开放判定修复

- 只有收到实际 UDP 数据报才报开放，合法零长度数据报也有效。
- 仅 Dial/Write 成功、服务表存在名称或没有响应，都不构成开放证据。
- 单条 probe 的拨号、写入、读取共用传入 timeout，每条 probe 使用独立连接；timeout 不是整个端口所有探针的总预算。
- OpenPort/ServiceMatch 仍只在开放结果上触发；不新增公开状态或结果字段。

升级后 UDP 开放结果可能减少；调用方应区分误报修正与网络/超时导致的无响应，并按自身实际使用范围验证集成。

## CLI 输出与兼容性

- `gomap port` 不再输出零开放端口的空结果；SDK 仍保留各目标结果。
- 现有公开结构、方法签名、JSON 字段及事件类型保持不变，新增独立方法不替换旧入口。
- Go 最低版本和依赖版本不变。主机发现报文类型、权限降级、错误返回、首页耗时及 UDP 结果的行为变化需要调用方留意。
- 不包含主动 Web 指纹实现；相关设计和计划文档不代表已交付功能。

## 升级

```bash
go get github.com/yrighc/gomap@v0.4.10
```

不需要本地 replace 或提交伪版本。既有调用方无需迁移 JSON/数据库结构；是否继续扫描、重试或取消远端任务仍由上层编排控制。

## 验证范围

发布检查沿用仓库格式、vet、`GOMAP_INTEGRATION=0 go test ./...` 和 CLI 构建；发布工作流构建 Linux/macOS/Windows 的 amd64/arm64 六种产物并生成校验和。

此前授权主机发现实网及无路由隔离验证记录见 [验收矩阵](../host-discovery-network-acceptance-matrix.md)。本次不重复大样本对比或现场探测；跨平台编译不等于所有平台实网验收。
